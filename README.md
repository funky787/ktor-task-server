# Ktor Task Server

Небольшой сервер на Ktor для работы с задачами.

В проекте есть GET, POST и DELETE запросы.
Данные хранятся в памяти без базы данных.

## Запуск

Для запуска нужен JDK 21.

Запустить можно через `Application.kt` в IntelliJ IDEA.

Также можно через терминал:

```bash
./gradlew run
